# CLAUDE.md — rules for agents in this repo

Retro Cable recreates 1990–2010 Bay Area cable TV on a homelab: a browser app first, then a tvOS app, fed by a deterministic scheduling server. Claude Code (cloud) writes all code. Hermes on Brandon's Mac runs local build and test; Hermes on the homelab deploys and patches.

## Read first

1. `docs/STATUS.md` — the current phase. Work only on that phase unless the task says otherwise.
2. `docs/plan.md` — the approved build plan and source of truth.
3. `docs/specs/*.md` — per-area specs (created in Phase 1 from the plan). Where a spec and the plan disagree, the spec wins for its area; say so in the PR.

## Layout

| Path | Contents |
| --- | --- |
| `server/` | Python 3.12, FastAPI, SQLite, scheduler package, worker jobs |
| `web/` | TypeScript, React, Vite: the TV screens and `/admin` |
| `tvos/` | SwiftUI app, Phase 9 onward; project generated by XcodeGen |
| `catalog/` | YAML inputs: channels, holidays, carriage, templates, overrides |
| `design/tokens.json` | Design tokens shared by web and tvOS |
| `ops/` | Compose files, Caddy snippet, allowlisted scripts, Hermes skills |
| `tools/` | Fixture generator and dev scripts |

## Commands (created in Phase 1, keep them working)

- `make bootstrap` installs toolchains and dependencies.
- `make fixtures` generates fake media into `.fixtures/` (gitignored).
- `make dev` runs the stack locally on fixtures.
- `make lint` runs ruff, mypy --strict, tsc and eslint.
- `make test` runs everything; `make test-server`, `make test-web`, `make e2e` run parts.
- `make api` regenerates `server/openapi.json` and the web client.
- `make stack-up` / `make stack-down` start and stop the Docker test stack (`ops/compose.test.yml`) on `127.0.0.1:8080`; `make e2e-stack` runs Playwright against it.

## Definition of done for every PR

1. Tests were written first and pass (`make test`); lint is clean (`make lint`).
2. If the API changed, `make api` was run and the generated client is committed.
3. If behavior changed, the matching spec in `docs/specs/` is updated in the same PR.
4. PRs touching `web/`, playback or `ops/` carry the `local-test` label.
5. The PR description follows the template: what changed, how it was tested, assumptions.

## Scheduler invariants (never break)

- A schedule is a pure function of (channel, simulated date, catalog version, seed). Inject the clock; never read wall-clock time inside the scheduler.
- Simulated time = chosen year + today's month/day + local wall-clock time in the configured zone (default `America/New_York`). Feb 29 falls back to Feb 28.
- No episode airs before its US debut or synthetic premiere date.
- No channel appears before its launch, except channels marked `library: true`.
- Programs run back to back: no gaps, no overlaps, correct across midnight and DST.
- Admin edits and the AI manager change inputs (catalog, weights), never generated schedules.

## Media and data

- No real video, audio or copyrighted media in the repo, CI or test logs. Use `make fixtures`.
- Never log signed media URLs, device tokens or API keys.
- The only external metadata source at runtime is TMDB, reached directly or through Brandon's LAN Seerr, from the worker.

## Security

- LAN only. The Caddy snippet rejects non-private client IPs; never add port forwards or public endpoints.
- Secrets live in GitHub secrets or a host `.env`; commit only `.env.example`.
- The self-hosted Mac runner serves only this private repo.

## Never

- Push to `main`, force-push a shared branch, or merge your own PR.
- Skip, delete or weaken a test to make CI pass.
- Hand-edit generated code (`web/src/api/generated/`, `.pbxproj`).
- Add a dependency without naming it and the reason in the PR description.
- Change release or secret-handling workflows without `[ci]` in the PR title.

## Handoffs

- Hermes on the Mac posts `local-test` results as PR comments. When a comment mentions `@claude` with a failure report, fix it on the same branch. After three failed rounds, stop and summarize what you tried.
- Deploys happen only through `ops/deploy.sh`, run by Hermes on the homelab.
