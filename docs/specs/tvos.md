# tvOS spec

Phase 9: the Apple TV app. Written Nov 11 2026 from `docs/plan.md` (Frontend; tvOS app (Phase 9)), the browser app as it runs today (`web/src`, `web.md`) and the TV API (`api.md`, `server/openapi.json`). The browser app is the working reference: where this spec is silent, the tvOS app does what the browser does. Where this spec and the plan disagree, this spec wins for its area; each difference is listed under "Differences from the browser app and the plan". Related specs: `web.md`, `api.md`, `scheduler.md`. The look (layout, sizes, colors, motion) is in `docs/design/tvos.md`; what is built and how to build it is in `tvos/HANDOFF.md`.

## The API the app uses

All read calls are `GET`; times are ISO 8601 with offset in the catalog zone; `year` is 1990–2010 or 0 for All Years.

| Call | When | Used for |
| --- | --- | --- |
| `/api/version` | Power-on screen | "Server v0.0.0 · c8e0e3d" |
| `/api/channels?year=` | Launch, year change, return from background, simulated midnight; per focused year in the year picker | The dial (channels with `on_air: true`, by number), the simulated `now`, `date`, `weekday`, `timezone` |
| `/api/tune/{channel}?year=` | Every tune, year change, queue refill, return from background, media failure | `current`, `next` (3 slots), `offset_seconds`, `now`. Each slot's `media_url` is a host-relative signed path, resolved against the server URL; null for filler |
| `/api/guide?year=&date=MM-DD&start=HH:MM&hours=13.5` | Opening the guide | Every channel on the dial with its slots for 13.5 h from the window start |
| `POST /api/watch` | Watch reporting | `WatchReport`, fire and forget, 204 |

The server base URL is `https://tv.home.tabaska.us` in every build Brandon installs (real certificate, so no App Transport Security exceptions). Tests may override it with a launch argument or environment variable (for the Docker test stack on `127.0.0.1:8080`); any ATS allowance that needs is limited to local networking in the test configuration. The app never logs, prints or shows a `media_url`, its `exp` or `sig`, or any token.

## Screens and states

### Power on

The app opens here on a cold launch, like the browser.

- "RETRO CABLE", then "Mountain View, CA · 1998" (the stored year's label; "All Years" for year 0), then "Press SELECT to turn on the TV".
- The server line reads "Tuning…" while `/version` loads, "Server v0.0.0 · c8e0e3d" once it answers, "No signal" if it fails. Under it, the app's own version and build ("App 1.0 (12)"), so Brandon can tell which sideload is installed.
- Select or Play/Pause turns the TV on: Live TV on the stored channel, with the banner. Back leaves the app (system behavior).

### No signal

- Shown instead of Live TV when the TV is on and the lineup (`/channels`) has failed with no lineup fetched yet: the era-style card "NO SIGNAL" and "Can't reach the cable box server. Retrying…".
- The app retries every 5 s, with no input needed, and goes to Live TV by itself as soon as a lineup arrives.
- A failed `/tune` with a lineup in hand is not "no signal": the channel stays, the banner title reads "Tuning…", and the tune is retried every 5 s.

### Live TV

- Full-screen video, aspect-fit on black, so 4:3 is pillarboxed and 16:9 fills. No system transport bar, scrubber, info panel or subtitles menu ever appears.
- **Tuning.** The app plays `current` from its position in the schedule: simulated now − slot start, worked out when the item is ready to play (not when the request was sent), so request time doesn't leave the picture behind. The position is clamped to 0.25 s before the end of the file.
- **While tuning**, the old channel's picture and sound stop at once and a "Tuning…" state shows until the new channel's first frame (the browser shows color bars with "Tuning…"; the look is the design spec's).
- **Auto-advance.** When the slot ends on the simulated clock, the next slot plays. Programs are never cut: if the file is still playing with at most 5 s left (seek rounding, buffering drift), it finishes first, then the next slot starts. Before the queue runs out (once the slot playing is the second to last one fetched), the app fetches `/tune` again; the answer restarts at the slot playing now.
- **Duration mismatch.** When a file's real length differs from its slot by more than 3 s, the app logs the title, season and episode and both lengths in seconds ("The Simpsons S5E12: file runs 1381.0 s but its slot is 1376 s (+5.0 s)"), never the URL. It doesn't cut or stretch the program.
- **Filler** (`kind: filler`, no media): color bars with the slot's title.
- **Bumpers.** A bumper with media plays it. A bumper without media shows the station ID slate: number and call sign ("02 KTVU"), the channel name, and "Up next 8:27 Seinfeld" (the next program, skipping bumpers).
- **Demo feeds.** When the media path is a demo feed (`/media/_demo/`, the test stack), the picture carries the browser's slate: the title and "S5 · E12 — Bart Gets Famous", "Feature presentation" for a movie, or the call sign and "Up next: …" for a bumper. Real media never gets it.
- **Media failures.** If a file fails to load or play (refused, expired signature, unplayable), the app tunes again once for a fresh URL and plays it at the live position. If that also fails, it shows the filler card with the slot's title until the slot ends, then advances. It never sits on a frozen frame.
- **Off-air channels** are never tuned: channels with `on_air: false` (not launched in the chosen year) are not on the dial.
- **Stored channel off the dial.** When the stored channel isn't on the chosen year's dial (Adult Swim in 1998), the lowest-numbered channel on the dial plays, but the stored channel stays remembered until the viewer tunes another one, so going back to 2005 brings Adult Swim back.

### Info banner

- Shows for 4 s after: every tune (channel up/down, last channel, a guide pick), turning the TV on, a year change, returning from the background, and every banner press (below). Each restarts the 4 s. The 4 s run on real time, never simulated time. The clock (top corner) shows only while the banner does.
- **Contents**, matching the browser:
  - Channel number, two digits ("02"), and call sign with network ("KTVU FOX").
  - Title. For a bumper, the channel's name instead, with no episode line, badges or description. "Tuning…" before the tune answers.
  - Episode line: "Bart Gets Famous · S5 E12"; for a movie, premiere year and running time ("1998 · 1h 25m"); empty for filler.
  - Badges: NEW (never on bumpers or reruns), the holiday name in upper case ("HALLOWEEN") while it is in force, and PRETEND PREMIERE (with the hollow diamond) on `transplant: true` slots.
  - The description, at most two lines, ellipsised. No description line, and no empty space, when `description` is empty.
  - Progress bar from simulated now between start and end, with the start and end times ("7:33", "7:56").
  - "Next 7:56 The Simpsons": the next program, skipping bumpers. Nothing when there is no next program.
  - The year: "Year 1998", or "All Years".
  - Remote hints: "▲▼ Channel · SELECT Guide · ⏯ Last channel".
- The clock reads "7:34 PM" over "Wednesday, Nov 11, 1998", in the server's time zone.

### Guide

- Opened with Select from Live TV. The window starts at the current half hour of simulated time and shows 90 minutes: the day ("Wed 11/11") and three half-hour labels ("7:30 PM", "8:00 PM", "8:30 PM"). One `/guide` request covers 13.5 h from the window start (12 h of scrolling plus the 90-minute window). The window stays where it was opened while the guide is open; reopening the guide re-centers it.
- **Header**: "GUIDE", the "All Channels" tab, the clock and long date, and the year badge ("1998" or "All Years").
- **Grid**: every channel on the dial by number, seven rows visible. Each row's channel column shows the number and call sign; the tuned channel's row is marked. Cells match the browser exactly:
  - Programs at their true run times; each bumper is folded into the cell before the next program.
  - A cell that started before the window reads "from 7:52".
  - After the start time, the kicker: "· NEW" (bold, focus gold) and "· MOVIE".
  - A holiday cell has a 3 pt bar on its left edge; the name is in the details panel and the banner, not in the cell.
  - A transplanted show has the hollow diamond before its title.
  - Cells that ended before simulated now are dimmed.
  - Narrow cells: measured against the 1526 pt cell area, under 120 pt a cell drops its time and kicker and keeps the ellipsised title; under 40 pt it shows no text, and its accessibility label carries the title.
- **Focus** starts on the tuned channel's row, on the cell airing now. The focused row stays fourth from the top, except near the first and last rows.
- **Details panel** for the focused cell:
  - "02 · KTVU FOX · 7:33 – 7:56 PM", the title, and the episode title.
  - Badges: "S5 · E12", NEW, MOVIE, the holiday, PRETEND PREMIERE.
  - "Rerun · first aired Thu, Feb 3, 1994" ("New" for a new episode, "(pretend)" after the date for a transplant). Filler reads "No programming scheduled" with no synopsis.
  - The synopsis, at most two lines: the description, else the episode line, else the title.
  - "Loading the guide…" while loading. "No signal" when the request fails, retried every 5 s while the guide shows. Select does nothing until the guide has loaded; Back always works.
- **Live picture-in-picture**: the tuned channel keeps playing, with sound, in the PiP box. It is the same playback as Live TV (opening the guide doesn't retune or rebuffer), and it auto-advances the same way.
- **Footer hints**: "SELECT Watch · ▶❚❚ Change year · BACK Live TV" (the design's wording), and the pretend-premiere key on the right.

### Year picker

- Opened with Play/Pause from the guide. "SET YOUR YEAR" header.
- **Grid**: 1990–2010 in three rows of seven; "All Years" alone on a fourth row. Focus starts on the current year, and the current year is marked differently from focus.
- **Moving**: arrows clamp at the edges (no wrap). Down from the third row reaches All Years; Up from All Years returns to the third row.
- **Left panel**: "Today on your TV is" and the focused year's date from `/channels` ("Wednesday, November 11, 1998"; the year label while it loads). Under it, "Each channel plays what had aired by this date, new episodes and reruns mixed." For All Years, today's real date and "All Years: every channel on, airing every season of every show, whenever it first aired."
- **Dial panel**: "On the dial in 1998", every channel by number with its two-digit number, name and note:
  - "On air"
  - "Always on (classics)" for library channels
  - "Your playlist" for movie channels
  - "Hidden until 2001" (dimmed) for channels not yet launched
- **Fetching**: each year's lineup is fetched 120 ms after focus lands on it and kept while the picker is open. A failed request is retried after 1 s, 2 s and so on up to 5 s, so the dial never stays empty.
- **Select** sets the year, saves it, returns to Live TV, retunes (the stored channel if it is on the new dial, else the lowest-numbered one) and shows the banner.
- **Back** returns to the guide, with its window and focus as they were, and changes nothing.
- The picker hides and silences the picture. Returning to Live TV or the guide always shows the channel at its live position, never a paused frame.

## Siri Remote

| Input | Power on | Live TV | Guide | Year picker | No signal |
| --- | --- | --- | --- | --- | --- |
| Swipe or click up | — | Channel up (next higher number on the dial; wraps from the highest to the lowest) | Row up (keeps the time; stops at the first row) | Move up | — |
| Swipe or click down | — | Channel down (wraps) | Row down (stops at the last row) | Move down | — |
| Swipe or click left / right | — | Show the banner | Previous / next cell; the window scrolls by half hours to reveal it, never before the opening window and never more than 12 h ahead | Move left / right | — |
| Select (click) | Turn on | Open the guide | Tune the focused row's channel to what airs now, back to Live TV | Set the year and retune | — |
| Hold Select | — | Nothing in this build (reserved for "like"; never opens the guide) | — | — | — |
| Play/Pause | Turn on | Last channel | Open the year picker | — | — |
| Back | Leave the app | Show the banner when hidden; leave the app when it shows | Back to Live TV, same channel, no retune | Back to the guide | Leave the app |
| TV button | System (Home) | System | System | System | System |

- One click, or one swipe step, moves one channel, row or cell. Swipes move cell by cell; they never skip a cell without the details panel showing it.
- **Rapid flipping**: each press tunes at once, with no debounce, and only the last channel pressed plays. Answers for channels already flipped past are dropped. The banner follows every press.
- **Last channel** is the channel tuned before the current one in this session; Play/Pause toggles between the two. It is not saved across launches, and does nothing when there is none or it isn't on the current dial.
- **Number entry** (digits in the browser) has no Siri Remote equivalent and is not offered.

## Channel change time

- From the press to the new channel's first frame, under 1.5 s (the plan's target for both frontends), on the LAN with real media. The same target holds for a year change and for a guide pick.
- The app measures each tune (press to first frame) and keeps the last 50 in a debug log Brandon or the engineer can read from Xcode's console: channel id and milliseconds only, no URLs.

## Persisted state

- `UserDefaults` keys `rc.year` and `rc.channel`, the browser's localStorage keys.
- **Year.** A missing or invalid stored year falls back to 1998; a stored 0 restores All Years.
- **Channel.** The channel is saved when the viewer tunes it (up/down, last channel, guide pick), not when the app falls back to another channel because the stored one is off the dial.

## Watch reporting

The app reports what is watched the way the browser does (`web.md`, M5; `api.md`, M5), for the weekly station manager:

- **Sessions.** One session per program (an `episode` or `movie` slot with a `show` id) playing on a channel, full screen or in the guide's PiP. Bumpers and filler aren't programs and are never reported.
- **Report body** (`WatchReport`):
  - `session`: a random 32-character hex id per session.
  - `device`: `"appletv"`; the browser sends none.
  - `channel`, `item` (the slot's `show`), `kind`, `season`, `episode` and `year` (0 for All Years).
  - `offset`: seconds into the program at tune-in, from simulated now and the slot start, capped at the runtime.
  - `runtime`: the slot's seconds, at least 1.
  - `seconds`: real wall-clock seconds since the session began, capped at the runtime.
  - `ended`.
- **When it reports**:
  - Every 60 s while the program plays, with `ended: null`.
  - `program_end` when the next program starts on the same channel and year.
  - `tune_away` on a channel change or a year change, or when the year picker hides the picture.
  - `power_off` when the app goes to the background.
  - A session's end is sent once.
- **Short sessions.** Under 10 s (flipping past a channel) is never sent.
- **Fire and forget.** Tuning never waits on a report. Failures are silent and not retried; nothing about a report is logged.

## Background, foreground and long runs

- **Going to the background** (TV button, Home, another app) stops playback and ends the watch session with `power_off`. The banner timer and retries stop.
- **Coming back**: the app fetches the lineup again (the simulated date may have changed) and tunes again at the live position, so the picture is what airs now, never the frame it left. The screen it was on is kept, and Live TV shows the banner. A guide whose window opened more than 30 minutes before simulated now reopens at the current half hour, with focus on the tuned channel's program now; the check runs on return and again against the `now` of the lineup fetched on return, since the monotonic clock may not have run while the Apple TV slept. The year picker stays up with the picture off; leaving it retunes. A cold launch (the system ended the app) starts at power on.
- **Simulated midnight.** When the simulated date changes, the app fetches the lineup again, so a channel that launches that day (Adult Swim on Sep 2, 2001) joins the dial.
- **Screensaver.** It doesn't start while Live TV or the guide's PiP is playing.

## Simulated time

- Simulated now is the server's `now` from the latest `/tune` (else the latest `/channels`) plus the time elapsed since that answer arrived, on a monotonic clock. The Apple TV's own date and time zone are never used for the schedule.
- Every displayed time uses the server's `timezone` (default `America/New_York`). The banner's 4 s and all retry delays run on real time.

## Out of scope for this phase

- Admin, settings, device pairing, likes (hold Select stays reserved until there is an API for them), tune-latency and stall telemetry to the server, number entry.
- TestFlight, fastlane, App Store Connect, Top Shelf, the paid developer account.
- 4K, HDR, Dolby Vision or Atmos.
- Viewing away from the LAN.

## Differences from the browser app and the plan

| Topic | Browser / plan | tvOS | Why |
| --- | --- | --- | --- |
| Opening the year picker | Y key, or the banner's Year button | Play/Pause in the guide (the plan's mapping); the banner isn't focusable | The Siri Remote has no Y key, and Select on Live TV opens the guide |
| Back from the year picker | Returns to Live TV | Returns to the guide, as it was | The guide is where it was opened |
| Hold Select = like (plan) | Not built | Reserved, does nothing | No likes API yet; adding one is a server change out of scope here |
| Number entry | Digits tune by number | None | No digits on the Siri Remote |
| Guide load failure | "No signal" until reopened | Retried every 5 s | A TV has nobody to press reload |
| Banner "Next" | Blank when the next slot is a bumper | Next program, skipping bumpers | The browser's blank looks like a bug; worth fixing there too |
| Lineup refresh | Once per year change | Also on return from background and at simulated midnight | An Apple TV app runs for days |
| Media failure | Waits for the slot to end | One fresh retune, then the filler card | Signed URLs expire after 4 h |
| Watch `device` | None | `"appletv"` | The station manager can tell the two apart later |
| Going away | `pagehide` → `power_off`; hidden → flush | Background → `power_off` | tvOS suspends background apps |
| Power on | Version line | Version line plus app version | Brandon can tell which sideload is installed |
| Telemetry (plan) | Tune latency event | Local debug log only | No telemetry endpoint yet |

### Persistence

- **TV-32** The year and channel are saved in `UserDefaults` (`rc.year`, `rc.channel`) and restored on the next launch. A missing or invalid year falls back to 1998, and a stored 0 restores All Years. — Unit
- **TV-33** A stored channel that isn't on the chosen year's dial plays the lowest-numbered channel instead, without overwriting the stored channel. Choosing a year where it is on the dial tunes it again. Last channel is not saved across launches. — Unit

### Watch reporting

- **TV-34** One session per program (episode or movie with a `show`) playing full screen or in the PiP, sent to `POST /api/watch`. The body is a random 32-hex `session`, `device: "appletv"`, the channel, item, kind, season, episode and year (0 for All Years), the `offset` at tune-in capped at the runtime, the `runtime`, and wall-clock `seconds` capped at the runtime. The server accepts it with 204. — Unit, Hands-on (rows appear in the Sunday report)
- **TV-35** The app reports a heartbeat every 60 s. It ends a session with `program_end` when the next program starts on the same channel; with `tune_away` on a channel or year change, or when the year picker opens; and with `power_off` when the app goes to the background. A session ends once. Sessions under 10 s, bumpers and filler are never sent. — Unit
- **TV-36** Reporting never delays a tune, a failed report is dropped silently, and nothing about a report is logged. — Unit
